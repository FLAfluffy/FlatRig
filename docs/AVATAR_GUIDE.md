# FlatRig アバター作成ガイド

パーツ分けした立ち絵の PSD から、VRChat で動く平面アバターを作り、自分の顔の動きで動かすまでの手順です。
Unity や VTube Studio を使ったことがない人でも進められるように、ソフトの準備から順に書いています。

顔の動きは、VTube Studio のトラッキングの値を FlatRig Bridge が VRChat に送って動かします。

## 全体の流れ

| | やること | 使うもの | 回数 |
|---|---|---|---|
| 1 | 用意するものをそろえ、絵の権利を確認する | — | 最初だけ |
| 2 | ソフトを入れて設定する | VCC・Unity・VTube Studio・VRChat | 最初だけ |
| 3 | PSD を用意する | お絵かきソフト | アバターごと |
| 4 | PSD を部品に分けて書き出す | FlatRigPSD.exe | アバターごと |
| 5 | Unity でアバターを作る | Unity(FlatRig ツール) | アバターごと |
| 6 | VRChat で試し、アップロードする | Unity(VRChat SDK) | アバターごと |
| 7 | 顔の動きで動かす | VTube Studio・FlatRigBridge.exe | 遊ぶたび |

---

## 1. 用意するもの

### 1.1 そろえるもの

- Windows の PC
- VRChat のアカウント(アバターをアップロードできる状態のもの。条件は VRChat の公式の案内を確認してください)
- トラッキング用の Web カメラ、または VTube Studio に対応したスマートフォン
- FlatRig 一式(`FlatRig` フォルダ。配布 zip を展開したもの)
  - FlatRigBridge.exe・FlatRigPSD.exe: アプリ本体
  - FlatRigTools.unitypackage: Unity 用のツール
- パーツ分けした PSD(1.2 の条件を満たすもの。描き方は 3 章)

このあとの手順で、次のソフトを入れます(2 章)。

- VRChat Creator Companion(VCC): VRChat 用の Unity プロジェクトを作るソフト
- Unity(VCC の案内に沿って入れるバージョン)と VRChat SDK Avatars 3.10 以降
- VTube Studio(PC 版)

### 1.2 絵の権利について(必ず確認)

- 使う絵は、**自分で描いたもの** か、作者から **VRChat のアバターとしての利用(アップロード・公開)と改変を許可されたもの** にしてください。
  配布素材は、規約で「アバターへの利用」「Unity などへの取り込み」「VRChat へのアップロード」が許可されているか確認してください。
- Live2D のモデルデータ(.moc3 など)や、他の人のモデルから取り出した画像は使えません。FlatRig が読むのは PSD だけです。
- 画像生成 AI を使った絵は、そのサービスの規約(商用利用・公開の可否)も確認してください。

## 2. ソフトを入れて設定する(最初だけ)

### 2.1 VCC と Unity を入れ、アバター用のプロジェクトを作る

1. VRChat の公式サイトから **VRChat Creator Companion(VCC)** をダウンロードして入れます。
2. VCC を起動します。Unity Hub や Unity が入っていなければ、VCC の案内に沿って入れます。
3. VCC でアバター用(Avatars)の新しいプロジェクトを作り、Unity で開きます。

### 2.2 FlatRig の Unity ツールを入れる

1. 2.1 のプロジェクトを Unity で開きます。
2. FlatRig 一式の **FlatRigTools.unitypackage** を、Unity の Project ウィンドウにドラッグ&ドロップします。
3. 「Import Unity Package」の画面が出たら、**「Import」** を押します。
4. Unity の上のメニューに **FlatRig** が出れば完了です。ツールは `Assets/FlatRig/Tools` に入ります。

この作業はプロジェクトごとに 1 回だけです。FlatRig の新しい版を受け取ったときは、同じ手順で入れ直すと上書きされます。
以前に Package Manager の「Add package from disk…」で入れていた場合は、先に Package Manager からそのパッケージを削除(Remove)してください。

### 2.3 VTube Studio を入れて設定する

1. **VTube Studio**(PC 版)を入れて起動し、好きなモデルを読み込みます(FlatRig が使うのは顔の動きの値だけです)。
2. カメラ(またはスマートフォン)のトラッキングを始めます。
   手で腕を動かしたい場合は、Webcam の設定で **「Face and hand tracking」** を選びます(7.4)。
3. 設定の **「APIの起動(プラグインを許可)」** を ON にします。ポートは 8001 のままにします。

### 2.4 VRChat の OSC を有効にする

VRChat を起動し、**Action Menu → Options → OSC → Enabled** にします。

## 3. PSD を用意する

FlatRigPSD.exe は、PSD のレイヤーを **自動で部品(前髪・目・口・体など)に分けます**。
多くの PSD はレイヤー名を変えずにそのまま使えます。自動の分け方が違っていても、書き出す前の確認画面で直せます(4 章)。

### 3.1 最低限そろえたいレイヤー

| 部品 | 動き | |
|---|---|---|
| 顔(輪郭・肌・耳など) | 頭の回転の中心 | **必須** |
| 左右の白目・黒目 | まばたき・目線 | 推奨 |
| 閉じた口・開いた口 | 口の開閉・横幅 | 推奨 |
| まつ毛・眉・後ろ髪・前髪・体 | まばたき・上下・揺れ | あると自然 |

足りない部品があっても書き出せます。その部品の動きが付かないだけです(顔だけは必須です)。

### 3.2 描き方の注意

- 隠れる部分も描いておきます。部品は別々に動くので、重なりの下が見えることがあります。
  - 顔は、目・眉・口の下の肌も塗っておきます(まばたきで目が縮むと見えます)
  - 後ろ髪は、顔の裏側まで描いておきます
  - 体は、あごの下の首まで描いておきます
  - 前髪の下の額も塗っておきます
- 口: 開いた口は上の端を基準に下へ伸び縮みします。閉じているときは見えません。
  閉じ・半開き・開きの口を別々の絵で描いた場合は、伸び縮みせずに絵を入れ替えます(3.3)。
- 目: まばたきは、まつ毛を下げながら平たくし、白目と黒目のまつ毛より上を隠して表現します(縦には縮めません)。閉じた目の線を別に描く必要はありません。
  - 白目の上部の影は、別のレイヤー(名前に「目」と「影」を含む。例: 「右目の影」)にしておくと、まつ毛と一緒に下がり、白目の外にはみ出した部分は隠れます。
  - 瞳のハイライトは、別のレイヤー(名前に「ハイライト」を含む。例: 「右ハイライト」)にしておくと、黒目と一緒に動きます。目を細めたときは、まぶたに押されて少し下がります(すぐには隠れません)。
- 使える描画モード: 通常・乗算・スクリーン・覆い焼き(リニア)・オーバーレイ。それ以外は通常として扱います。
- クリッピングしたレイヤーは、元のレイヤーと一緒に重ねます。
- グループの不透明度・描画モードは反映しません。グループは「通過」か「通常・100%」にしてください。
- 高さ 3000px を超える PSD は、自動で 1/2・1/3 … に縮小します。

### 3.3 表情と、絵の差し替え(任意)

目や口を表情ごとに描き分けておくと、VRChat で表情を切り替えられます(7.2)。無くても動きます。
PSD で表示しているレイヤーが「通常」の表情になります。表情用のレイヤーは非表示のままで大丈夫です。

- 表情の目・口は、通常の目・口と同じ位置に描きます(キャンバスの大きさも同じにします)。
- 口の絵の差し替え: 名前に「閉じ」「半開き」「開き」を付けた口の絵があると、口の開き具合で絵を入れ替えます。
  - 例: 「口のまとめ」グループに「笑顔の口閉じ」(表示)・「笑顔の口半開き」・「笑顔の口開き」(非表示)。
  - 表示している口と同じ名前の組(「笑顔の口〜」)が通常の口に、別の名前の組(「尖った口閉じ」「尖った口開き」)はその名前の表情(「尖った」)の口になります。
- まばたきの閉じた目: 「閉じた左まぶた」のような閉じた目の絵があると、まばたきで閉じきる直前にその絵に入れ替えます。
  - 名前に表情の名前がある閉じた目(「閉じた笑顔左まぶた」)は、その表情(「笑顔」)の目になります。
  - それ以外の名前の閉じた目(「そのまま閉じた左まぶた」など)は、確認画面で好きな表情に割り当てます。
- グループ「表情:名前」(例: 「表情:怒り」)の中のレイヤーは、その名前の表情の部品になります(目・口は名前と位置から、それ以外は追加パーツ)。
- 自動で分からなかったものや、表情を足したい・直したいときは、確認画面の「表情」で設定します(4 章)。
- 表情の目は、まばたき・目線では動きません。「^ ^」のような閉じた目や、目尻を下げた目を 1 枚の絵として描いてください。
  その表情の間は、その側の白目・黒目・まつ毛・影・ハイライトが隠れます。眉は通常の眉がそのまま動きます。
- 表情の口は、その表情に選んだ絵だけで開閉します(閉じ・開きの 2 枚なら半分で切り替え、1 枚ならずっとその絵)。
- 表情は 15 個まで作れます。

### 3.4 手足を動かす部品(任意)

Unity の「手足をトラッキングに合わせる」を ON にすると、腕・脚が VRChat の体の動き(デスクトップの歩き・VR の手・フルトラの脚)に合わせて関節で曲がります。
OFF のときは、手足の部品は体と一緒に動くだけです。

- 腕は上腕・前腕・手、脚は太もも・すね・足を別のレイヤー(またはグループ)にします。左右も別にします。
  - 名前は役割名(`arm_l_upper` など。付録 A)か、「上腕」「二の腕」「前腕」「手」「太もも」「すね」「靴」などを含めます。左右は画面の位置で決まります(画面の左が `_l`)。
  - 「腕」「脚」だけの名前は、上腕・太もも(腕・脚全体が 1 枚で、肩・股関節で回る)になります。
  - 両腕が 1 枚に描かれていると曲げられないので、体になります(はみ出した影や線で少しだけ反対側にかかっている程度なら、絵のある側の腕・脚になります)。
  - 「袖」「袖の裏」や部位の無い「腕」「脚」のレイヤーは、同じ側の上腕・前腕(太もも・すね)のうち重なりの大きい方にまとまります。
  - 「ひざ」「膝」「肘」は、太もも・上腕の中に収まる小さな絵ならそちら、太ももの下へ伸びていれば(膝から下を描いた部品)すね・前腕になります。
- 関節は重ねて描きます。上腕と前腕、前腕と手が少し重なるようにし、肘・膝・手首は丸く描き足します(曲げたときに隙間が出ないように)。関節の位置は重なった部分から自動で決まります。
- 腕の下に隠れる胴体も描いておきます(腕が上がると見えます)。
- 絵の腕は下ろした形のままで大丈夫です。
- できないこと: 腕を前に出しても短くは見えません。腕を体の後ろへ回す動き、しゃがむ・寝そべる動きは表現できません。

### 3.5 自動の分け方を確実にしたいとき

自動の分け方は、次の順で決まります。

1. 役割名(付録 A)が付いたレイヤー・グループは、その役割にします(一番確実です)。
2. 役割名が無ければ、レイヤー名・グループ名から推測します。
   例: 「前髪」「後ろ髪」「横髪」「白目」「瞳」「まつ毛」「眉」「鼻」「口内」「上唇」「下唇」「顔」「輪郭」「耳」「腕」「袖」「ひざ」「スカート」など。
   英語(`HairFront`・`Eye_L_White`・`UpperArm.L` など。区切りや大文字小文字は自由)、よくある略語(瞳の中の `hi`・`反射光` = ハイライト)、中国語の名前の一部にも対応します。
   レイヤー名で分からなければ、親グループの名前で決めます(「右目」グループの中の「hi1」はハイライト、など)。
3. 名前で分からないものは、位置と重なり順で決めます。顔の範囲にあって顔より奥なら後ろ髪、手前なら顔の飾り、それ以外は体と一緒に動きます。

細かな決まり:

- 髪・横髪・帽子は、顔より奥にあれば後ろ髪、手前にあれば前髪と同じ動きになります(「横髪の裏」なども自動で後ろ髪)。
- 「リップハイライト」「鼻ハイライト」「髪のハイライト」は瞳のハイライトにしません(目・瞳のグループの中か、名前に目の言葉があるハイライトだけ)。
- 名前に「鼻」「はな」「ハナ」「nose」が付いたレイヤー(「鼻ハイライト」「鼻の影」、「鼻」グループの中のものも)は、まとめて 1 つの鼻にします。
- 表示されているレイヤーは基本的にすべて使います(配布素材の透かしなども消しません)。
- 使わないもの:
  - 非表示のレイヤー
  - 名前が `_` か `#` で始まるもの(下書き・参考画像用)
  - 「差分」「ガイド」「閉じ目」「ラフ」「下書き」「見本」「目安」などの名前のもの
  - 「背景」「用紙」「background」の名前のもの、一番奥でキャンバス全体を覆う名前の分からないレイヤー(背景)
  - 目や口の上に重なる「レイヤー 1」のような名前のもの
- 目・眉・口・鼻以外の部品は、PSD のレイヤーごとに別の部品になります(Unity の「表示順」でレイヤーごとに重なりを変えられます。5 章)。
  乗算などの描画モードのレイヤーは、1 つ下のレイヤーと同じ部品になります。
- 重なり順は PSD の順番のままです。

## 4. PSD を部品に分けて書き出す(FlatRigPSD.exe)

1. PSD ファイルを **`FlatRigPSD.exe` のアイコンにドラッグ&ドロップ** します。
   「PSD を読み込んでいます…」の小さな画面のあとに、**「FlatRig 部品の確認」画面** が開きます(大きな PSD は準備に少しかかります)。
2. 右の画像と左の一覧で、部品の分け方を確認します。
   - 左の一覧には、PSD のレイヤー(上が手前)と、それぞれの **部品**・**表情**・**決め方**(役割名・名前から・位置から・手動)が並びます。
   - 一覧でレイヤーやグループを選ぶと、右の画像でそこだけが濃く表示されます。右の画像をクリックしても、そこにあるレイヤーを選べます。
   - 「部品ごとに色分け」にすると、部品ごとに色を付けて表示します。色の見本が下に出ます。
3. 違うものがあれば、レイヤー(まとめて直すならグループ)を選び、下の **「選んだレイヤーの部品」** で正しい部品を選びます。
   - 例: 口が重なって見える → 下唇・口の中は「開いた口」、上唇は「閉じた口」
   - 例: 体の一部が消えている → そのレイヤーを「体」に
   - 入れたくないもの → 「使わない」(配布素材の透かしは消さないでください)
   - 手で直した行は青色になります。「自動の分け方に戻す」で最初の状態に戻せます。
   - 部品の選択肢は部位の順(髪 → 顔 → 眉 → 目 → 口 → 体 → 腕 → 脚)に並んでいます。「(左)」「(右)」は **画面の左右** です。
   - 左右がまとめて逆になっているときは **「左右を入れ替える」** を押します。目・眉・手足の左右と、表情の左目・右目の枠が入れ替わります(もう一度押すと戻ります)。
   - 閉じた目・半開きの口の絵(3.3)は、「閉じた目の絵」「半開きの口」を選びます。
     口を閉じ・半開き・開きの絵で入れ替えるときは、**「口は絵の差し替え」** にチェックを入れます(自動で分かれば最初から入っています)。
4. 表情を使う場合は、下の **「表情」** で設定します。
   - 「表情を追加」で名前を付けて表情を作ります。表情を選ぶと、右の画像がその表情の見た目になります。
   - 使うレイヤーを選び、**「表情「…」で使う枠」** で左目・右目・閉じた口・半開きの口・開いた口・追加パーツ(頬染めなど)を選びます。選ばなかった枠は通常の部品のままです。
   - 左の一覧の「表情」の列に、どの表情のどの枠で使うかが出ます。「名前を変更」「削除」もここで行います。
   - 表情は「表情」の欄の並び順で、VRChat のメニューに並びます。
5. 下の欄に「足りない部品」が出ていないか確認して、**「書き出す」** を押します(顔の部品が無いと押せません)。
6. 「書き出しました」と出れば成功です。PSD と同じ場所に `<PSD名>_FlatRig` フォルダができます。
   - `layers\layers.json`: Unity で読み込むファイル
   - `layers\preview.png`: 書き出した部品を重ねた画像
   - `mapping.json`: どのレイヤーをどの部品にしたかの記録

うまくいかなかったときは、理由と記録ファイルの場所が画面に出ます。

**もう一度直したいとき**: 同じ PSD をもう一度ドロップすると、前回の分け方で確認画面が開きます。
PSD のレイヤーを足したり名前を変えたりしたときは、`mapping.json` を削除してからドロップすると、自動の分け方からやり直せます。

## 5. Unity でアバターを作る

1. VCC から 2.1 のプロジェクトを開きます。
2. メニュー **FlatRig → Build From Layers** を開きます。ウィンドウの 1〜3 を上から順に進めます。

### 5.1 「1. レイヤー素材から平面アバターを生成」

| 項目 | 入れるもの |
|---|---|
| layers.json | 「参照…」で `<PSD名>_FlatRig\layers\layers.json` を選びます |
| アバター名 | アバターの名前(英数字と `_` `-`。64 文字以内) |
| キャンバスの高さ (m) | 絵の高さを何 m にするか。全身なら 1.4〜1.6 くらい |
| キャンバス下端の高さ (m) | 全身の絵は 0(足が床)。上半身だけなら 0.7〜0.9 くらい |
| アトラスの最大サイズ | 4096 |
| 手足をトラッキングに合わせる | 手足の部品(3.4)があり、腕・脚も動かしたいときに ON |

「アバターを生成」を押すと、Scene にアバターが置かれます。

- 「手足をトラッキングに合わせる」を ON にすると、アバターは Humanoid になります。Scene では腕が横に伸びた形(T ポーズ)に見えますが、VRChat では立った姿勢になります。
  - 腕を固定(初期値)・脚を固定(初期値): アバターを着たときの、Expression Menu の「腕を固定」「脚を固定」の状態です(既定はどちらも固定)。固定すると絵の元の姿勢に戻ります。
  - 手をカメラで動かす(初期値): アバターを着たときの、Expression Menu の「手をカメラで動かす」の状態です(既定 ON。7.4)。
- 表示順を開くと、部品の重なり順を変えられます(既定は PSD の重なり順)。上ほど手前で、ドラッグで並べ替えます。
  - 「(動かしている間)」の付いた行は、腕・手を動かしている間だけ表示する手前用の絵です(固定中は元の行の位置で描きます)。
  - 体・髪・顔などは PSD のレイヤーごとに並ぶので、同じグループの中の順も変えられます。
  - 目・眉・口・鼻と、同じ役割名を付けたレイヤー、乗算などの描画モードのレイヤー(とその 1 つ下)は、まとまったまま動きます。

### 5.2 「2. アニメータを生成」

params.json に、FlatRig 一式の `FlatRig\config\params.example.json` を選び、「アニメータを生成」を押します。

最初は既定の設定のままで大丈夫です。動かしてみて気になったら、次の項目を調整して「アニメータを生成」を押し直します(設定は次回も残ります)。

- 動きの大きさ(倍率): 「全体」とパーツごと(顔の向き・首のかしげ・体の揺れ・目線・眉・口の横幅など)の倍率で、1 が標準です。
  大きくすると、隠れていた描いていない部分が見えやすくなります。目線を 1 より大きくすると、黒目が白目からはみ出すことがあります。
- 閉じた口の絵を保つ開き具合: 口を絵の差し替えで動かす場合に、少し開いただけなら閉じた口の絵のままにする範囲です(既定 0.1 = 10%)。
- 表情(表情があるときだけ): 表情ごとのハンドジェスチャー(既定: 使わない)と、トラッキングの口の形(口角の上がり具合)で自動に切り替える表情(既定: 使わない)を選べます。

### 5.3 「3. VRChat の設定を生成」

**「VRChat 設定を生成」** を押します。VRChat のメニュー(Expression Menu)とパラメータが作られ、アバターに設定されます。

### 5.4 Unity の中で動きを確かめる(任意)

Unity の **Play** を押し、メニュー **FlatRig → Param Sliders** を開きます。
アバターを選んでスライダーを動かし、まばたき・口・顔の向きを確かめます。確かめたら Play を止めます。

---

## 6. VRChat で試し、アップロードする

1. Unity のメニュー **VRChat SDK → Show Control Panel** を開き、VRChat のアカウントでログインします。
2. **Builder** タブでアバターを選び、まずローカルテスト(**Build & Test**)でビルドします。
   VRChat のアバター一覧のローカルテスト用の欄から選んで、見た目と動き(7 章)を確かめます。
3. 問題なければアップロードします(**1.2 の絵の権利を満たしている場合だけ**)。

---

## 7. 顔の動きで動かす(遊ぶたび)

### 7.1 起動の順番

1. **VRChat** を起動し、作ったアバターに着替えます(OSC が Enabled になっていること。2.4)。
2. **VTube Studio** を起動し、モデルを読み込んでトラッキングを始めます。
3. FlatRig 一式の **FlatRigBridge.exe** をダブルクリックします。
   初回は VTube Studio に許可の画面が出るので **「Allow」** を押します。
4. FlatRig Bridge のウィンドウに **「中継中」** と出れば動いています。
5. VRChat の Expression Menu で **FlatRig** を ON にすると、顔の動きがアバターに反映されます。

FlatRig Bridge のウィンドウを × で閉じても、タスクトレイに隠れて動き続けます。やめるときは **[終了]** を押します。
VRChat と一緒に起動・終了させる設定もあります(FlatRig フォルダの README.txt)。

### 7.2 表情を変える

表情があるアバターでは、次のどれかで表情が変わります。

- Expression Menu の「表情」から表情を ON にします(OFF にすると戻ります。ジェスチャーより優先されます)
- 左右どちらかの手を、5.2 でその表情に選んだジェスチャーにします(両手が別の表情なら左手が優先されます)
- 自動の表情を選んだ場合: トラッキングで口角を上げます

### 7.3 自動まばたき

Expression Menu の「自動まばたき」を ON にすると、目の開閉だけトラッキングを使わず、自動のまばたき(10 秒に 3 回、不規則な間隔)になります。
目線や顔の向きなどはトラッキングのままです。ON/OFF はアバターを替えても保たれます。

### 7.4 手で腕を動かす(手足をトラッキングに合わせたアバター)

VTube Studio の手のトラッキングで腕を動かせます。

- VTube Studio の Webcam の設定で「Face and hand tracking」(顔と手)を選びます。
- Expression Menu の「手をカメラで動かす」が ON の間、カメラに手が映っていると、その腕が手の位置へ動きます(「腕を固定」が ON でも動きます)。手が映らなくなると、固定やトラッキングの状態に戻ります。
- 左右が逆になるときは、`FlatRig\config\settings.json` の `"hands"` の `"swap"` を `true` にします。
  settings.json が無ければ、`settings.example.json` をコピーして `settings.json` という名前にします。`"hands"` が無ければ、`settings.example.json` の `"hands"` の部分を写します。
- 動く範囲が狭い・広いときは、Unity の「動きの大きさ(倍率)」の「手の動く範囲(カメラ)」を変えて「アニメータを生成」を押し直します。
- 前後の動き・指・手首の向きは反映されません。手を速く動かすと検出が外れやすくなります。

## 8. 絵を描き直したとき

1. PSD を直したら、4 章の書き出しからやり直します。
2. Unity で、同じアバター名のまま 1〜3 のボタンを順に押し直します(上書きされます)。
3. アップロード済みのアバターを更新する場合は、6 章の手順でアップロードし直します。
   パラメータが変わった場合は、VRChat の **Action Menu → Options → OSC → Reset Config** を押してください。

## 9. うまくいかないとき

### PSD の書き出し

| 症状 | 確認すること |
|---|---|
| 部品が足りない・余計な部品がある | もう一度 PSD をドロップし、確認画面で部品を選び直して書き出します |
| 口がいくつも重なって見える | 確認画面で、下唇・口の中を「開いた口」、上唇を「閉じた口」にします |
| 「書き出す」が押せない・顔が無いと出る | 顔のレイヤーを「顔」にします(顔の部品は必須です) |
| 表情が書き出されない | 確認画面の「表情」で、その表情にレイヤーを選んでいるか確認します(レイヤーの無い表情は書き出しません) |

### Unity

| 症状 | 確認すること |
|---|---|
| メニューに FlatRig が無い | 2.2 の手順で FlatRigTools.unitypackage を入れます |
| 「生成できませんでした」と出る | Unity の Console に出ているエラーを確認します |
| 「VRChat SDK(Avatars)が見つかりません」と出る | VCC で作ったアバター用プロジェクトで開いているか確認します |
| 「アトラスが … 縮小されました」と出る | 画質が少し下がるだけです。気になる場合は「アトラスの最大サイズ」を上げるか、PSD を小さめに描くか、部品を減らします |
| 部品の縁に線が見える | 書き出しをやり直してから、Unity の 1〜3 を押し直します |

### 見た目・動き

| 症状 | 確認すること |
|---|---|
| 左右の目が逆に動く | `_l` は画面の左側です。確認画面の「左右を入れ替える」か、名前を入れ替えます |
| まばたきで目の跡が見える | 顔の部品に、目の下の肌を塗っておきます |
| 頭を動かすと髪の裏や首が欠ける | 隠れる部分を描き足します(3.2) |
| 表情が変わらない・メニューに「表情」が無い | 確認画面の「表情」で表情を作り、使うレイヤーを選んで書き出します。Unity の 1〜3 を押し直します |
| 表情の目・口の位置がずれる | 表情の絵を、通常の目・口と同じ位置(同じキャンバス)に描きます |
| 口を開くと口が消える・絵が切り替わらない | 確認画面の「口は絵の差し替え」を確認します(閉じ・開きの絵を描いたなら ON、口の中を伸ばすなら OFF) |

### 動かすとき

| 症状 | 確認すること |
|---|---|
| 「VTube Studio に接続中…」のまま | VTube Studio の「APIの起動(プラグインを許可)」が ON か、ポートが 8001 か確認します |
| 「VTube Studio の許可を待っています」のまま | VTube Studio の許可画面で「Allow」を押します |
| 「VTube Studio のモデル待ち」のまま | VTube Studio でモデルを読み込みます |
| 「中継中」なのにアバターが動かない | VRChat の OSC が Enabled か、Expression Menu の FlatRig が ON か確認します。アバターを更新した後なら OSC → Reset Config を押します |

ほかの症状は、FlatRig フォルダの README.txt の「うまく動かないとき」も確認してください。

## 付録 A. 役割名(命名規則)

レイヤーまたはグループに次の役割名を付けると、自動の推測を使わずにその部品になります。
半角英字で、大文字小文字は区別しません。`_` の代わりに `-`・空白、キャメルケース(`BackHair`・`EyeLWhite`)でもかまいません。
グループに付けた場合は、中のレイヤーを全部重ねて 1 つの部品にします。

| 役割名 | 部品 | 動き |
|---|---|---|
| `back_hair` | 後ろ髪(顔より奥のもの全般) | 頭と一緒に動く |
| `body` | 体・首・腕など | 体の揺れ |
| `face` | 顔(輪郭・肌・耳など) | 頭の回転の中心。**必須** |
| `eye_l_white` / `eye_r_white` | 白目 | まばたき |
| `eye_l_pupil` / `eye_r_pupil` | 黒目(瞳) | 目線、まばたき |
| `eye_l_lash` / `eye_r_lash` | まつ毛・上まぶたの線 | まばたき |
| `eye_l_shadow` / `eye_r_shadow` | 白目の上部の影(任意) | まばたき(まつ毛と一緒に下がる) |
| `eye_l_highlight` / `eye_r_highlight` | 瞳のハイライト(任意) | 目線、まばたき(まぶたに押されて少し下がる) |
| `brow_l` / `brow_r` | 眉 | 上下 |
| `nose` | 鼻(影・ハイライトも含めて 1 つ。任意) | 顔の向きに合わせてずれる(奥行き 0.25。目と眉の間くらい) |
| `mouth_closed` | 閉じた口(唇の線) | 口の横幅 |
| `mouth_open` | 開いた口(口の中・歯・舌・下唇) | 口の開閉 |
| `front_hair` | 前髪・横髪(顔より手前のもの) | 頭と一緒に、大きめの立体感 |
| `eye_l_closed` / `eye_r_closed` | 閉じた目の絵(任意。3.3) | まばたきで閉じきる直前に、通常の目と入れ替え |
| `mouth_half` | 半開きの口の絵(任意。3.3) | 口の開き具合で、閉じた口・開いた口の絵と入れ替え |
| `arm_l_upper` / `arm_r_upper` | 上腕(任意。3.4) | 手足の設定が ON なら、肩を中心に回る |
| `arm_l_lower` / `arm_r_lower` | 前腕(任意) | 同上、肘で曲がる |
| `hand_l` / `hand_r` | 手(任意) | 同上、手首で曲がる |
| `leg_l_upper` / `leg_r_upper` | 太もも(任意) | 同上、股関節を中心に回る |
| `leg_l_lower` / `leg_r_lower` | すね(任意) | 同上、膝で曲がる |
| `foot_l` / `foot_r` | 足(任意) | 同上、足首で曲がる |

- **`_l` は画面の左側、`_r` は画面の右側** です(キャラクターから見た左右ではありません)。画面左の目は `eye_l_…`、画面右の目は `eye_r_…` にします。
- 同じ役割で部品を分けたいときは、`役割名.好きな名前` にします。例: `back_hair.ribbon`、`front_hair.side`
  (目・眉・口・鼻は 1 つにまとめられます。同じ役割名が複数あれば 1 つの部品に重ねます)
- 奥行き(頭を動かしたときのずれ方)を変えたいときは、名前の後ろに `@数値` を付けます。−1(奥)〜 1(手前)。
  例: `back_hair.ribbon@-0.8`、`face.ear@0.1`。付けなければ役割ごとの標準値です。
- 役割名の付いていないグループは、その中を探します(例: 「頭」グループの中に `face` や `eye_l_white` があって大丈夫です)。役割名の付いていないレイヤーは、3.5 の 2・3 の方法で振り分けます。
